## 4-апта 1-тапсырма түсіндірмесі
`angle += 0.02f;` деп жазғанда және VSync өшірілгенде, үшбұрыштың қозғалысы уақытқа (секундқа) емес, кадр жиілігіне (FPS) тәуелді болып қалады. Қуатты компьютерде FPS жоғары болғандықтан объект өте жылдам айналады.

`angle += speed * dt;` өрнегін қолдану айналу жылдамдығын барлық компьютерде бірдей және кадр жиілігінен тәуелсіз етеді.
